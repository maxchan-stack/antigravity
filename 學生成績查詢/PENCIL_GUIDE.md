# ✏️ Pencil.dev VS Code 擴充套件新手指南

這是一份針對 **Pencil.dev** 的詳細操作手冊，教您如何從零開始在 VS Code 中進行 UI 設計並轉換為程式碼。

---

## 第一階段：安裝與啟動

### 1. 安裝擴充套件
1.  開啟 **VS Code**。
2.  點擊左側側邊欄的 **「擴充套件 (Extensions)」** 圖示 (或是按 `Cmd+Shift+X`)。
3.  在搜尋框輸入 `Pencil.dev`。
4.  找到 **"Pencil"** (通常由 *High Agency* 發布)。
5.  點擊 **[Install]** 安裝。

### 2. 登入帳號
1.  安裝完成後，按 `Cmd+Shift+P` 開啟指令面板。
2.  輸入 `Pencil: Login` 並按 Enter。
3.  系統會彈出瀏覽器視窗，請使用您的 Email 或 Google 帳號完成登入。
4.  登入成功後回到 VS Code。

### 3. 設定專案風格 (Design System)
首次使用時，Pencil 會詢問您的專案風格（如果沒問，可手動設定）：
1.  按 `Cmd+Shift+P`。
2.  輸入 `Pencil: Configure Design System`。
3.  選擇您喜歡的風格庫（新手推薦選擇 **Shadcn UI** 或 **Tailwind**），這決定了它產生的程式碼長什麼樣子。

---

## 第二階段：開始設計

### 1. 建立設計檔案
1.  在您的專案資料夾中，點擊右鍵或是新增檔案圖示。
2.  建立一個新檔案，檔名結尾必須是 `.pen` (例如：`LoginPage.pen`)。
3.  點擊兩下開啟這個檔案，您會看到一個類似 Figma 的空白畫布出現在 VS Code 編輯區。

### 2. 使用 AI 生成設計 (最快上手方式)
這是 Pencil 最強大的功能，讓 AI 幫您畫圖：
1.  在 `.pen` 畫布左側工具列，找到 **AI 對話框** (通常是星星✨或魔法棒🪄圖示)。
    *   **💡 快速鍵**：直接點擊畫布，按下 `Cmd + K` (Mac) 或 `Ctrl + K` (Windows) 也可以直接叫出 AI 輸入框！
2.  輸入指令，例如：「**幫我設計一個用 Email 登入的畫面，要有忘記密碼按鈕，配色使用藍色系**」。
3.  按下 Enter，等待幾秒鐘，畫面上就會出現畫好的 UI 元件。
4.  您可以繼續輸入：「**把按鈕改成圓角的**」或是「**標題字體再大一點**」，AI 會調整設計。

### 3. 從 Figma 匯入 (如果有現成設計)
1.  開啟您的 **Figma**。
2.  選取您要的設計區塊，按 `Cmd+C` 複製。
3.  回到 VS Code 的 `.pen` 畫布，按 `Cmd+V` 貼上。
4.  您的 Figma 設計就會變成可編輯的 Pencil 格式。

### 4. 手動調整
在此畫布上，您可以像操作 PPT 或 Figma 一樣：
*   **拖曳**元件位置。
*   點擊文字直接**修改內容**。
*   在右側屬性欄調整**顏色、邊距、字體大小**。

---

## 第三階段：輸出程式碼 (變現)

設計滿意後，我們要把它變成真正的網站程式碼：

### 1. 選取元件
1.  在畫布上，點選您要輸出的那個區塊（例如整個「登入卡片」）。

### 2. 轉換為程式碼 (Code Gen)
1.  在選取狀態下，點擊右鍵，選擇 **"Copy as Code"** (或是尋找介面上的 **</> Code** 按鈕)。
2.  選擇您要的格式，例如：
    *   **React + Tailwind** (最常用)
    *   **HTML + CSS**
3.  程式碼會自動複製到剪貼簿。

### 3. 使用程式碼
1.  建立一個新的程式碼檔案 (例如 `Login.jsx` 或 `Login.html`)。
2.  貼上剛剛複製的程式碼。
3.  存檔並執行，您就會看到跟設計圖一模一樣的網頁畫面了！

---

## 💡 小撇步 (Tips)

*   **版本管理**：別忘了把 `.pen` 檔案也 `git commit` 提交上去。這樣您的隊友拉下程式碼時，也能看到最新的設計圖，方便大家討論。
*   **善用 Component**：如果您常重複使用某個按鈕，可以在 Pencil 中把它設為 Component，這樣改一個地方，全部都會跟著變。

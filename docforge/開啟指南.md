# 圖片文件編輯 - 開啟與使用指南

## 🎉 專案已建構完成！

靜態檔案位於 `dist/` 目錄，檔案大小約 2.5 MB。

---

## 方案一：快速啟動（推薦）⚡

###步驟：
1. 雙擊 `start.sh` 檔案
2. 瀏覽器會自動開啟圖片文件編輯（http://localhost:8080）
3. 完成！

> � 首次執行時如果 Mac 提示「無法打開」，請：
> 1. 右鍵 > 打開
> 2. 或到「系統偏好設定 > 安全性與隱私」中允許執行

---

## 方案二：封裝成 macOS App 🖥️

### 安裝 Electron 相關依賴：

```bash
cd docforge
npm install --save-dev electron electron-builder concurrently wait-on
```

### 建構 App：

```bash
npm run electron:build
```

### 封裝結果：

建構完成後，您會在 `dist-electron/` 目錄找到：
- `圖片文件編輯.app` - 可執行的應用程式
- `圖片文件編輯-2.0.0.dmg` - 安裝映像檔

### 安裝方式：

1. 雙擊 `圖片文件編輯-2.0.0.dmg`
2. 拖曳圖片文件編輯.app 到「應用程式」資料夾
3. 完成！可以在 Launchpad 或應用程式資料夾開啟

---

## 方案三：直接開啟 HTML（最簡單但功能受限）

1. 直接開啟 `dist/index.html` 檔案
2. 用瀏覽器打開即可

> ⚠️ 警告：某些功能可能因 CORS 限制而無法使用，建議使用方案一或方案二

---

## � 建議使用場景

| 方案 | 適合場景 | 優點 | 缺點 |
|-----|---------|------|------|
| 方案一 | 日常使用 | 快速、簡單、不需安裝 | 需要 Python |

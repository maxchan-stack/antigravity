# 圖片文件編輯

專業級 PDF & 圖片處理工具箱 • 100% 本地端處理 • 完全免費

## 📦 已實作功能（10/10）

### PDF 工具（7個）
- ✅ PDF 合併器
- ✅ PDF 月分器
- ✅ PDF 旋轉器
- ✅ PDF 頁面移除器
- ✅ PDF 頁碼添加器
- ✅ 圖片轉 PDF
- ✅ PDF 轉 JPG

### 圖片工具（3個）
- ✅ 照片轉換工作站（支援 HEIC）
- ✅ 圖片壓縮機
- ✅ 圖片浮水印

## 🚀 快速開始

### 方案一：直接運行（推薦）
```bash
# 雙擊執行
./start.sh
```

### 方案二：開發模式
```bash
npm install
npm run dev
```

### 方案三：封裝成 App
```bash
npm install
npm run build
npm run electron:build
```

詳細說明請查看 `開啟指南.md`

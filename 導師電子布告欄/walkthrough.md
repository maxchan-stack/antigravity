# UI/UX 與全新功能優化成果報告書

本專案已成功導入今日課表、倒數計時器（導師可設定與刪除）、常用資源連結自訂化，以及多項核心功能的升級，並已同步完成雙管道部署（Google Apps Script + GitHub Pages）。

---

## 視覺與檢視功能升級

### 1. 直開式折疊整週課表功能 (Collapsible Weekly Timetable)
- **簡潔標題呈現**：首頁不再預設顯示今日課程列表，改以單純的「**課表**」為標題，並搭配「**展開課表**」按鈕，使首頁界面極致清爽。
- **點擊直接展開整週**：點擊展開後，直接呈現週一至週五完整的課表網格。
- **自動比對與當日高亮**：系統會自動根據當天星期幾，將當日整欄進行**淡綠色（rgba(90,140,110,0.08)）高亮背景與綠色粗體字標記**，使今日課程更加凸顯。
- **背景預拉取快取**：載入時在背景預拉取雲端課表，展開時為 0 延遲無縫呈現。
- **流暢收合**：再次點擊「收合課表」按鈕即可折疊，支援行動端窄螢幕左右滑動檢視。

### 2. 角色選擇頁面版面重排 (Layout Reordering)
- **UX 使用體驗升級**：將首頁中點選角色卡片後展開的「細項選擇按鈕」或「授權碼輸入框」在 HTML 結構中**向上移動**，使其直接緊隨於角色卡片正下方。
- **定位最下方**：將「課表」與「常用資源」區塊固定在首頁的**最底端呈現**。
- **優化成效**：這解決了之前使用者點選「班級幹部」或「小老師」身份後，輸入框被擠壓在課表與常用資源按鈕下方，導致必須手動向下滾動才能輸入密碼的 UX 缺陷。現在首頁最核心的「身份卡片與其驗證動作」一併呈現在上方，課表與常用資源作為輔助資訊靜待在最下方。

### 3. 倒數計時器配色優化 (Rose Red Theme)
- **視覺警示度提升**：倒數計時橫幅配色調整為莫蘭迪色系的**高質感紅玫瑰色**（Rose Red/Crimson）。
  * 背景採用柔和淡玫瑰底色（`rgba(219,68,85,0.06)`），邊框與文字採用優雅的玫瑰深紅（`#db4455`）。
- **學生頁面可見**：在公告主頁面（`page-board`）的「今日速覽儀表板」上方，同步顯示此橫幅，確保學生與家長一進入就能看見。

### 4. 今日課表轉移至雲端試算表管理 (Cloud Timetable Sheet)
- **自訂與修改**：今日課表正式轉為可由導師**自主修改管理**。
- **排除標題列優化**：網頁端分析課表資料時，會自動過濾並跳過試算表中包含「節次」或「星期」的第 1 列標題列（A1~F1），直接從第 2 列第 1 節課開始做 1 到 8 的課表排號。
- **操作指南**：導師只需點選後台的試算表連結，在 Google 試算表中新增一個名為「**timetable**」的工作表分頁：
  * 第一列（A1~F1）填寫標題（如：節次、星期一至五）。
  * 第 2 列至第 9 列填寫第 1 節至第 8 節的課程（例如 A2 寫 1，B2~F2 寫週一至週五 the 課程）。

### 5. 自訂資源入口連結 (Flexible Quick Links)
- **非強迫填寫**：解除原本必須填滿 4 個連結的強迫限制。導師在設定時，只要有填寫「標題」與「網址」的連結才會呈現在首頁。留空欄位會被安全忽略。

## 載入效能與速度優化 (Performance Optimization)

針對網頁可能因為慢速網路（例如 4G 收訊不佳）或 Google Sheets API 延遲導致卡在 Loading 畫面與顯示為「`--月--日`」的問題，完成以下效能升級：

1. **非阻塞漸進式渲染（Non-blocking UI Rendering）**：
   - **0 毫秒極速開屏**：網頁載入時不再阻塞等待網路請求。系統會立即以本機時間渲染日期（取代 `--月--日`），並同時渲染本地預設課表與資源連結，隨即直接進入角色選擇畫面。
   - **背景靜默同步（Silent Background Fetch）**：網路數據載入（包含跑馬燈、自訂課表與常用連結）改在背景默默運行。當加載成功時，畫面上的課表與常用連結會無縫切換為您在試算表設定的自訂版本，達到零卡頓的流暢體驗。

2. **並行資料請求（Promise.all Parallel Loading）**：
   - 將原本序列化的讀取改為**同時發送三個獨立的工作表讀取請求**（公告、設定、課表），大幅將初次開屏的等待時間**縮短 50% 左右**。

3. **資料複用快取機制（Bulletins Global Cache）**：
   - 引入全域變數快取 `BULLETINS_CACHE`。當使用者在列表與月曆檢視之間切換、進行分類篩選、或是小老師查看個人歷史列表時，直接讀取快取中的資料，**達到 0 秒即時渲染**，避免反覆呼叫 Google API 造成網路延遲與卡頓。
